# Goal Reader ⚽📖

Five minutes a day of reading practice for first graders — on iPad, iPhone and Mac.

Open the app: **https://learn-to-read-eight.vercel.app**. On iPad, use Safari → Share → Add to Home Screen.

- **Soccer Story Time on the home screen** — 12 new seven-sentence stories: eight sourced player biographies and four original tales about school, simple equipment, rest and teamwork. Listen to a complete story with Fish Audio, or read together one sentence at a time. Your place is saved per player; questions are optional.
- **Flexible Story Time** — read one sentence, tap Continue; skip a part or section anytime.
- **Two Fish voices** — choose Teacher or Josh in the always-visible parent Settings.
- **Sound games** (rhyme, robot-talk blending, clapping syllables) — audio only.
- **Words:** review with spaced repetition, then 3 new words a day: hear it, sound it out, and read it; continue after a correct reading.
- **Read a sentence** made only of words the child can decode.
- **Story time** (10-minute sessions): read sentence by sentence, 3 questions, a word-meaning or rhyme bonus, put it in order.
- **Independent iPad practice:** automatic speech checks with a listen-and-repeat fallback. Unchecked practice stays separate from accuracy and mastery; assisted grown-up modes remain available.
- **Write it** (optional): trace, write from memory with finger or Apple Pencil, or build with letter tiles.
- **Rewards:** every word read is a goal; goals earn blocks that build a stadium.
- **Anytime soccer:** the persistent ⚽ Play button opens three shots without leaving the current screen. Choose free kicks, penalties or targets; place the ball left/center/right and near/far. Reading resumes after the game; writing and timed-reading state are retained.
- **Soccer:** pick a jersey number and jersey/shorts/cleat colors, then play before reading and between practice activities. Three swipe-to-shoot free kicks with saves, misses, weak shots, post/bar and wall collisions; one optional replay per scheduled break, or repeated rounds in anytime play. Play time and soccer scores stay separate from reading minutes and rewards.
- **Child-led pacing:** take your turn during teacher demonstrations, answer without waiting for narration to finish, and continue after one unverified listen/repeat attempt. Unverified practice never becomes a checked reading pass.
- **Parent area** (Spanish, with English toggle): minutes per day, tricky words, story skills, Florida B.E.S.T. benchmarks, school FAST scores.

Aligned with the Florida B.E.S.T. ELA grade 1 standards. Never shows a picture before the child reads (Florida bans three-cueing). All content is original.

## Run
```bash
npm install
npm run dev            # http://localhost:5173
npm run check          # unit tests + typecheck + content validation
npm run build && npm run e2e
```
